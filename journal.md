# Journal de bord

## 2026-10-04

### Travail effectué

* Création du dépôt sur GitHub et clonage sur mon ordinateur.
* Configuration de la clé SSH et du nom et de l’adresse e-mail utilisés pour les commits.
* Création du journal de bord sur GitHub, puis récupération avec `git pull`.
* Découverte des commandes Unix : `cd`, `ls`, `pwd`, `cat`, `less`, `mkdir`, `cp`, `mv` et `rm`.
* Comptage des annotations et des lieux pour 2016, 2017 et 2018.
* Classement des 15 lieux les plus cités pour chaque année, puis pour le mois de mars, toutes années confondues.
* Enregistrement des commandes et des résultats dans le dossier `Exercices`.

### Pendant le cours

Pendant le cours, j’ai d’abord travaillé avec le terminal et les commandes Unix. J’ai appris à utiliser les chemins et les commandes comme `cd`, `ls` et `pwd`.

J’ai aussi appris la routine pour travailler avec Git : `git pull`, modifier les fichiers, `git add`, `git commit`, `git push`, puis `git tag` quand le travail est terminé. 

### Après le cours

Après le cours, j’ai refait quelques commandes Git pour mieux comprendre comment le dépôt local et GitHub sont liés.

Je vais aussi continuer à pratiquer les commandes Unix, surtout pour être plus à l’aise avec le terminal.
